# Recursos visuales

Conservar diagramas editables y exportaciones juntos en una carpeta con nombre inglés. Un diagrama sencillo puede vivir como Mermaid dentro de su página; un Draw.io conserva su fuente y SVG.

El piloto definirá estilo, densidad, tipografía y uso de interacción. Todavía no existe un sistema visual aprobado. Los gráficos cuantitativos identifican los datos que los generan; una maqueta se rotula como tal.

Las figuras de [harness](harness/overview.svg), [escenarios](harness/scenarios.svg) y [ensamblaje](harness/context-assembly.svg) son síntesis conceptuales propias. Sus fuentes y alcance están en el [piloto editorial](../docs/editorial-pilot.md). Se regeneran con `python3 scripts/generate_editorial_figures.py`; el generador conserva etiquetas, geometría y colores. No editar a mano las exportaciones SVG. No contienen materiales institucionales ni imágenes de las referencias privadas.
