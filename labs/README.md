# Laboratorios

Pruebas pequeñas para observar mecanismos. Todavía no hay una ejecución que sustente afirmaciones en el catálogo.

Un lab declara pregunta, alcance, cómo ejecutar, entradas y resultado esperado. Empieza con README.md y run.py si basta. Añade dependencias aisladas cuando las necesite; no instala todos los frameworks para leer la wiki.

Los resultados citados se guardan en runs/run-YYYYMMDDtHHMMSSz-suffix con manifiesto y resultados. Registrar revisión del código, configuración, versiones, fuentes de datos y límites. No simular una ejecución ni borrar evidencia negativa relevante. Servicios externos y llamadas de pago no se ejecutan por CI de forma implícita.

Cuando una pieza necesite usuarios, despliegue o releases propios, pasa a su repositorio. La wiki conserva explicación y referencia a una revisión identificada.
