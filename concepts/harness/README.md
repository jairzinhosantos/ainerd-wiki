# Harness

Este borrador define la pregunta del primer estudio: **¿qué decisiones de ingeniería convierten las capacidades de un modelo en comportamiento de sistema?** La definición y su alcance se contrastarán con fuentes públicas; esta primera entrega no fija una definición universal.

## Qué queremos comprender

Cómo se relacionan control, contexto, herramientas, estado y ejecución. Qué incluyen distintos autores dentro del término harness y qué responsabilidades sitúan fuera. Cómo cambian estas fronteras al estudiar una implementación específica.

## Primer recorrido

Partiremos del [ensamblaje de contexto](context/context-assembly.md) y estudiaremos [Pi](../../tech/pi/README.md) como primera implementación. Las relaciones conceptuales y las capacidades verificadas de una tecnología se mantendrán separadas.
