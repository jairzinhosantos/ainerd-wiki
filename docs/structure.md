# Estructura y crecimiento

La estructura activa separa concepts, tech, architectures, benchmarks, labs, catalog, assets, docs, templates y scripts. README.md es la entrada al recorrido de Harness Engineering. Una carpeta organiza lectura; no declara una taxonomía universal de la IA.

## Rutas de expansión

| Área | Próximos contenidos cuando se estudien |
|---|---|
| concepts/systems | agent-concepts.md, agents-and-workflows.md |
| concepts/harness | agent-loop.md, tools-and-capabilities.md, planning-and-coordination.md, runtime-and-execution.md |
| concepts/harness/context | retrieval-and-rag.md, context-compaction.md |
| concepts/harness/memory | short-term-memory.md, long-term-memory.md, memory-lifecycle.md |
| concepts/models | inference.md, fine-tuning.md |
| concepts/operations | ai-operations.md, evaluation.md, observability.md, safety-and-control.md |
| tech | Un perfil por tecnología; capabilities.yml y timeline.yml con los primeros datos reutilizables |
| architectures | Patrones, arquetipos y escenarios propios; código en labs o repo independiente |
| benchmarks | Expedientes fechados con observaciones, método y manifiesto |
| labs | Una pregunta, código, dependencias cuando existan y resultados citados |

Una sección se extrae cuando tenga alcance y profundidad propios. La independencia de IDs permite mover rutas sin perder identidad. No crear una página por cada palabra ni carpetas de ejecuciones ficticias. Las áreas sin artículos tienen una portada que explica su propósito y siguiente pregunta.
