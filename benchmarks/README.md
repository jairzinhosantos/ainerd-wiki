# Comparativas y mediciones

[Definiciones y alcance de harness](2026-10-harness-definitions/README.md): comparación documental de perspectivas y 27 proyectos, con fuentes y corte identificado. Todavía no hay benchmarks ejecutados.

Una comparación documental usa type comparison; un benchmark ejecutado usa type benchmark. Cada resultado identifica versiones, escenarios, criterios y límites. Una tabla documental no se presenta como medición.

Cada comparación se conserva en una carpeta YYYY-MM-description con README.md, observations.json y manifest.json; method.md cuando el método necesite desarrollo separado. El manifiesto lista archivos de entrada relativos y sus SHA-256, y un corte temporal. Las observaciones usadas se conservan, sin volver a leer silenciosamente los perfiles más recientes.

Los datos tendrán fuente, componente, versión, evidencia y condiciones por observación. Desconocido no significa ausencia. Las correcciones conservan el resultado citado anterior y explican el reemplazo.
