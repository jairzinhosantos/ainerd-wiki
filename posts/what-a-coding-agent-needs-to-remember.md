Most "memory" features store everything and retrieve by similarity. After a month of pairing with coding agents every day, the facts that mattered fit on one screen.

## The list

1. How I like to be corrected (early, bluntly).
2. Which commands are safe to run without asking.
3. The three files that explain the architecture.
4. What I tried last week that did not work, and why.

Everything else can be re-read from the repository in seconds. The agent does not need to remember my code; it needs to remember **me**.
