# Pi

Este perfil delimita el primer estudio tecnológico. Todavía no se ha fijado una versión ni comprobado una matriz de capacidades; no se presenta una recomendación de adopción.

## Alcance por fijar

Identificar el proyecto y paquete precisos, la versión o commit que examinaremos y sus límites. Después seguir en documentación y código cómo intervienen el loop, el ensamblaje de contexto y los puntos de extensión pertinentes.

## Pregunta del piloto

¿Cómo se prepara el contexto de una llamada en la revisión estudiada y dónde podríamos observar o modificar ese proceso? La explicación conceptual vive en [ensamblaje de contexto](../../concepts/harness/context/context-assembly.md).

## Evidencia que necesitamos

Fuentes primarias con localizadores, código en una revisión fija y una prueba si la conclusión exige observar comportamiento. Las capacidades quedarán como desconocidas hasta verificar su alcance.
