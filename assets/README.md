# Recursos visuales

Conservar diagramas editables y exportaciones juntos en una carpeta con nombre inglés. Un diagrama sencillo puede vivir como Mermaid dentro de su página; un Draw.io conserva su fuente y SVG.

El piloto definirá estilo, densidad, tipografía y uso de interacción. Todavía no existe un sistema visual aprobado. Los gráficos cuantitativos identifican los datos que los generan; una maqueta se rotula como tal.
